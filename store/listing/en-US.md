## Full description

```
Replicant303 is an analog-modeled virtual bassline synthesizer and 16-step sequencer for Android, inspired by the legendary TB-303. Built from the ground up with a native C++ audio engine (Oboe / AAudio at 48 kHz), it delivers the authentic resonance, squelch, squealing accents, and slides essential to acid techno and electronic music.

KEY FEATURES

• VIRTUAL ANALOG DSP ENGINE:
  - Sawtooth and Square waveforms with detailed transistor waveshaping.
  - 4-pole (24 dB/oct) diode ladder low-pass filter with self-oscillation.
  - Classic controls: Cutoff, Resonance, Envelope Mod, Decay, Accent, and Volume.
  - Integrated analog-style distortion/overdrive with Drive, Tone, and Mix knobs.
  - Direct 48 kHz real-time audio pipeline running in high-priority C++ without GC latency.

• STEP SEQUENCER FOR PURE ACID:
  - 16-step sequencer with intuitive pitch entry and octave shifts (Down / Up).
  - Dedicated per-step Slide (portamento) and Accent flags.
  - Built-in preset vault with factory acid patterns.
  - Generative procedural pattern mutate/randomizer (GEN button) for instant inspiration.
  - Background audio playback via optimized Foreground Service for live performances.

• TACTILE INTERFACE & LIVE VISUALS:
  - Responsive 13-key tactile keyboard designed for rapid riff creation.
  - Real-time vector oscilloscope and reactive frequency spectrum display.
  - Cyberpunk skins (Neon Green, High-Voltage Red, Cyber Amber).
  - Adaptive layout optimized for both mobile phones and tablets.

• HARDWARE USB MIDI INTEGRATION:
  - Full USB Host support for USB MIDI 1.0 and Universal MIDI Packet (UMP / MIDI 2.0).
  - MIDI In: control notes, velocity, and filter sweeps from any hardware MIDI controller.
  - MIDI Out & Clock: send notes and master MIDI Clock (Start/Stop/Clock tick) to grooveboxes and modular rigs.
  - MIDI CC mapping for hands-on control over Cutoff, Resonance, and Decay.

• MIDI PATTERN EXPORT / IMPORT:
  - Export patterns to standard Standard MIDI Files (.mid) to use in your favorite DAW (Bitwig, Ableton Live, FL Studio, Reaper).
  - Import external MIDI basslines directly into the sequencer.

100% PRIVATE, AD-FREE, AND INDEPENDENT:
- No advertisements or pop-ups.
- No in-app purchases or subscriptions.
- Collects zero personal data, telemetry, or analytics.
- Zero network permissions: works 100% offline anytime, anywhere.
```
